Dash light decoder

  • Check engine, steady

    Usually a sensor or an emissions part. Safe to drive in. Book this week.

    Book the code read

  • Check engine, flashing

    An active misfire. Ease off, park when it is safe and call us before driving on.

    Call the shop

  • Brake or ABS

    Low fluid, worn pads or an ABS sensor after road grit. Drive gently and book today.

    Book a brake check

  • Engine temperature

    Overheating. Pull over, shut it off and let it cool. Call before you restart.

    Call the shop

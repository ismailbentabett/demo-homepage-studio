# Media Plan — hvac-C (Shadeline Heating & Cooling)

## Hero
- **Key:** `equip-condensers` (matched outdoor units in a desert yard)
- **Section:** 1 (Hero, diagonal split family 11)
- **Crop:** `object-position: 50% 40%` — keeps both condensers centered behind the 115° type mask; left unit sits in sunlit zone, right unit in shaded zone.
- **Treatment:** photo grade + terracotta overlay `linear-gradient(135deg, rgba(154,52,18,.3) 0%, transparent 60%)` to reinforce adobe tone.
- **Caption:** Matched outdoor condensers on concrete pads in a desert yard, block fence behind, hard midday light casting short shadows.
- **Note:** Original brief seed called for a rooftop package unit (`hero-C1`) but that key does not exist in the approved manifest. This is the strongest available alternative: residential, desert, no faces, no readable brands. The diagonal split treatment and type mask distinguish it from hvac-A's use of `hero-A1`.

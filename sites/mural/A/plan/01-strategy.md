# Strategy — mural-A

## Buyer
Homeowners (30-55) with a blank stucco wall, nursery, or tagged garage; small business owners wanting a photo-worthy storefront wall. Fear: "What if I hate it once it's on the wall?" and "No idea what this costs."

## Objection to answer first
"What if I hate it?" → Show the full path from sketch to wall so they see where they say yes before paint touches stucco.

## Path
Process-led: sketch → scale → grid → pounce → block → detail → clear coat. Each step is a frame. The chalk grid is the signature that ties every section together.

## Tone
Color-led: sun-bleached stucco coral field, jacaranda violet + palm-shadow green partners, chalk white type. Warm, hard LA afternoon light.

## Differentiators vs clichés
- Not an Instagram grid with no prices.
- Not "bringing walls to life" copy.
- Not a long artist bio before hire.
- Instead: visible process, sample price ranges by sq ft, grid coordinates as navigation, chalk-line signature throughout.

## Tools
Grid preview, Wall size price range, Timeline counter, ZIP checker, multi-step quote form.

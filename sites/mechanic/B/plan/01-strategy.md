# Strategy — mechanic-B (Plain Code Auto Repair)

1. **The one job.** A worried driver with a check-engine light or strange noise lands, reads "we test first, then explain in plain words," and books a drop-off or texts a photo within 8 seconds. Primary action: call/text; secondary: book drop-off.
2. **Homeowner's first 5 seconds.** H1 kicker "{{biz.city}} auto diagnosis" + headline "The code is only the start." One proof line: "We test the part, show you the reading, and give you a plain answer before any work." Two buttons above the fold: [[call]] and [[quote Codes btn-ghost]]. Phone visible in header and sticky mobile bar.
3. **Contractor's first 5 seconds.** No other Billings shop pairs every scan-tool code with a plain-English translation and shows the actual mm / volts / degrees reading. That pairing becomes the signature: machine says X, we say Y.
4. **Objections → sections.**
   - "They'll find a hundred things" → Proof section with sample pad-mm, battery-test, coolant-temp readings.
   - "I'll pay for a part that won't fix it" → Guarantee block + review where Curt tested sensors before replacing converter.
   - "Is it safe to drive?" → Warning-light decoder tool output with drive/tow verdict.
   - "I won't understand what they tell me" → Every service card uses code/plain pair.
   - "They'll keep my car a week" → Drop-off routine timeline in process story.
   - "They'll do work first and call after" → Promise line in hero + process step "Your yes" before repair.
5. **Conversion paths.** Primary: [[call]] in header, hero, sticky mobile bar. Secondary: [[quote ...]] on each service card → multi-step form pre-filled via data-service. Tool path: warning-light decoder or code lookup → result → "Book a drop-off" CTA → form with complaint pre-filled. ZIP checker confirms service area before form.
6. **What this direction is NOT.**
   - Not a repair-order timeline (that is mechanic-A).
   - Not a seasonal/local story magazine (that is mechanic-C).
   - Not a generic "we fix everything" grid of service icons with no numbers.

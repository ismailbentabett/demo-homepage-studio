# Design system — carpenter-B

## Fonts

- **Display:** Anybody (variable). Axes: wdth 50-150, wght 100-900. Preload: yes (normal, weight 400 800, stretch 75%). Used for h1, h2 only.
- **Text:** Figtree (variable). Axis: wght 300-900. Body 400, lead 450, strong 600.
- **Accent:** DM Mono (static). Weights 300, 400, 500. All measurements, prices, tolerances, tick labels, tool readouts.

## Type scale

Ratio 1.2 mobile → 1.333 desktop. Display tracking -0.03em, line-height 0.92. Body line-height 1.5, measure 60-72ch. Nothing under 13px.

```css
--fs--1: clamp(0.75rem, 0.7rem + 0.25vw, 0.8125rem);   /* 12-13px, captions */
--fs-0:  clamp(0.9375rem, 0.88rem + 0.3vw, 1.0625rem);  /* 15-17px, body */
--fs-1:  clamp(1.125rem, 1rem + 0.5vw, 1.3125rem);      /* 18-21px, lead */
--fs-2:  clamp(1.35rem, 1.15rem + 0.8vw, 1.75rem);      /* 21-28px, h3 */
--fs-3:  clamp(1.62rem, 1.3rem + 1.2vw, 2.375rem);      /* 26-38px, h2 */
--fs-h1: clamp(2.6rem, min(9vw, 9.5svh) + 0.1rem, 5rem);/* tuned for Anybody wdth 75% */
```

Body: var(--fs-0), font-weight 400. Lead paragraph: var(--fs-1), font-weight 450, font-variation-settings "wght" 450. Headings: text-wrap: balance. Body: text-wrap: pretty.

## Space

```css
--s-1: 4px; --s-2: 8px; --s-3: 12px; --s-4: 16px;
--s-5: 24px; --s-6: 32px; --s-7: 48px; --s-8: 64px; --s-9: 96px;
--s-10: 120px; --s-11: 160px;
```

Section padding (vertical): tight 64px, normal 96px, loose 128px. Blueprint alternates. Horizontal: max-width 1200px, margin auto, gutter 24px.

## Grid

12 columns desktop, 8 tablet, 4 mobile. Gutter 24px. Max-width 1200px. Left margin column 64px reserved for story-pole ruler on desktop; collapses to top-edge horizontal ruler on mobile (<768px).

## Radius

0 everywhere except buttons and inputs: 2px. Tags and pills: 999px. Photo frames: 0 (sharp architectural edges).

## Shadow

Only on mobile bar and popover: `0 2px 8px rgba(26,28,32,.12)`. No shadows elsewhere.

## Rules

Weight: 1px solid var(--rule). Color: var(--rule) per tone. Story-pole ruler: 1px solid var(--ink) with 8px tick marks every 12in, 4px ticks every 6in. Active tick: 2px solid var(--accent).

## Motion tokens

```css
--ease-out: cubic-bezier(.23,1,.32,1);
--ease-io: cubic-bezier(.77,0,.175,1);
--dur-press: 120ms;
--dur-ui: 200ms;
--dur-page: 520ms;
--dur-story: 900ms;
--dur-stagger: 60ms;
```

No bounce, no elastic.

## Components

- **Buttons:** primary (--btn-bg/--btn-ink), secondary (transparent bg, 1px border var(--ink)), text (no bg, underline on hover). Min-height 48px, padding 0 var(--s-5). Focus: 3px solid var(--focus), offset 3px.
- **Input:** border 1px solid var(--rule), bg var(--bg), height 48px, radius 2px. Focus same as button.
- **Card:** border 1px solid var(--rule), padding var(--s-6), radius 0. Height-tag strip on left: 32px wide, mono, var(--accent) on t-paper.
- **Sample tag:** inline pill, 1px border var(--accent), color var(--accent), font-family DM Mono, font-size var(--fs--1), padding 2px 8px, radius 999px.
- **Frame:** aspect-ratio set per slot, overflow hidden, grade filter applied. No border.
- **Header:** height token --header-h: 64px. Logo left, nav center, [[call]] right. Background var(--bg), border-bottom 1px solid var(--rule).
- **Mobile bar:** fixed bottom, height 64px, two buttons (Call + Price it), shadow, hides on scroll down and when #contact visible.
- **Story-pole primitive (.story-pole):** position fixed left:0 top:0 width:64px height:100vh (desktop); contains tick marks generated by CSS repeating-linear-gradient; active tick positioned via --sw-p CSS var set by app.js. Mobile: horizontal bar top:var(--header-h) height:32px, ticks rotate 90deg. Hook: data-sw-signature.

## Photo grade

All photos: `filter: saturate(.8) contrast(1.05) sepia(.06) brightness(1.02)`. Cool, even, architectural. No warm overlay. Optional duotone on t-deep sections: multiply #2c2e33 at 15% opacity.

## Focus

`:focus-visible { outline: 3px solid var(--focus); outline-offset: 3px }`. Forced-colors: `border: 2px solid ButtonText` on buttons and inputs.

# Strategy — landscaper-B (Half Inch Landscape Co., Austin TX)

1. **The one job.** An Austin homeowner worried about water bills or a browning lawn lands, sees their yard’s water budget in seconds, and clicks “Price it” to get a sample range for a drip/xeriscape conversion within 8 s.
2. **Homeowner’s first 5 seconds.** H1: “Xeriscape & Drip Irrigation in Austin, TX” + kicker “Every gallon accounted for”. Primary button “Price it”, secondary “Call (512) 555-0117”. Proof line: “Mon–Fri 6:30–4:30 · Round Rock to Buda · 4.8 ★ (Sample rating)”. The water-budget calculator sits above the fold beside the headline on desktop; on mobile it stacks directly under the buttons.
3. **Contractor’s first 5 seconds.** Nobody else in Austin puts an irrigation-controller-style water budget tool in the hero with zone-by-zone gallons and a price hand-off. That controller UI becomes the signature.
4. **Objections → sections.**
   - “Plants die by August” → Native beds service card + review from Karen J. (Dripping Springs).
   - “Sod washes out / soil never fixed” → Drip conversion + irrigation check cards with process photo.
   - “No idea what it costs” → Hero water-budget tool + project-size estimator + sample prices block.
   - “Crew wrecks irrigation lines” → Process story (site walk → test → install → label/map) with crew-from-behind photo.
   - “Wrong plants for here” → Plant picker tool + native-texas photo slot.
   - “Watering-day confusion” → Watering-day finder tool (sample rule) + hours/open-now.
5. **Conversion paths.** Primary: “Price it” → multi-step quote form (#contact) pre-filled via `data-service`. Secondary: sticky mobile bar with Call + Price it; text link `sms:` in header. Tool → form hand-off: water-budget output carries yard size and turf/native ratio into the estimator; estimator result pre-fills service + scope. Phone always visible in header and mobile bar on 390.
6. **What this direction is NOT.**
   - Not A’s soil-profile depth gauge (vertical horizon bands, color-led terracotta, slab serif).
   - Not C’s botanical-marker shade garden (dark-led oak/moss palette, arch-masked hero, serif voice).
   - Not a lush estate-lawn template: no drone stripes, no “oasis” copy, no generic icon grid. This page reads like an irrigation controller dashboard in bright limestone light with mono numbers.

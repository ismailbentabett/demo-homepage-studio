# windowdoor-C · Strategy (Oak Canopy, Jacksonville, direction C: LOCAL STORY)

1. **The one job.** A Jacksonville owner of an old (or salt-beaten) house lands from "wood window repair jacksonville" /
   "window replacement for old house" and, within 10 s, finds their neighborhood on the page and either calls, or texts a
   photo of the window. Price-it (estimator / repair-or-replace) is the 3rd path for the researcher.

2. **Homeowner's first 5 s (390 + 1440).** Kicker: "Window & door work · {{biz.city}}, {{biz.state}}". h1 (centered,
   condensed, ≤ 8 words): "Every Jacksonville window, Riverside to the Beaches." (city via token). Buttons: Call
   {{biz.phone}} (primary, brick) + "Text a photo" (sms:, secondary). Proof line: "{{proof.rating}} Sample rating ·
   {{hours|today}} · Repair priced before replace". Bottom of hero: the elevation marquee (window types by neighborhood).

3. **Contractor's first 5 s.** Nobody in Jacksonville has a site that knows *which* house you live in: the page is drawn as
   the St. Johns route, each neighborhood a stop with its build years and the window that fits, and the drawn window at
   each stop opens as you arrive. Signature = River Route Stops (route line + mile dot + drawn sash that lifts).

4. **Objections → section.**
   - "They'll rip out my old wood windows" → #stops Riverside/Avondale stop + #repair tool + guarantee line (facts).
   - "The price goes up when they find something" → #prices (sample ranges per opening/per window) + estimator.
   - "Impact windows will look like an office" → Beaches stop (cottage-look impact) + Brian T. review.
   - "Historic district: will I get in trouble?" → Springfield stop + Historic help service + Denise O. review (hedged).
   - "Patio slider leaks in afternoon storms" → Mandarin stop + Angela R. review.
   - "Can't compare quotes" → #prices table, "your measured quote lists each opening".
   - "Do you even come to my side of town?" → #area ZIP checker + 10 areas as river stops.

5. **Conversion paths.** Primary: tel: (hero, header, mobile bar left). Secondary: sms: "Text a photo" (hero, bar right).
   Tool hand-off: repair-or-replace verdict, style-by-age pick and estimator count prefill the form (`data-prefill`)
   → #contact "Quote" form (once). On 390 the sticky bottom bar holds Call + Text (56px), visible after the hero
   buttons leave the viewport; header keeps a phone icon button 48px.

6. **What this is NOT.**
   - Not A's window schedule / jamb-framed photo / serif tags (no tables-as-signature, no W1/D1 tags).
   - Not B's dark spec plates / mono label values / dusk lanai / pinned photo.
   - Not storm/hurricane-led: impact glass is one stop (the Beaches), never the opening pitch; no countdowns, no radar.

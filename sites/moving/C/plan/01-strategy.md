# Strategy — moving-C (Kestrel Moving & Haul, Boulder CO)

## 1. The one job of this page
A Boulder homeowner or renter lands here needing a local move, canyon haul, downsizing sort or junk pickup; within 8 seconds they see their town named, a sample hourly range, and a way to call or price it without a form wall.

## 2. The homeowner's first 5 seconds
- Trade + town: "Boulder movers & haul-away" in the h1, Kestrel name beside it.
- A way to act: phone number and "Price it" button above the fold.
- One reason to believe: a proof line under the h1 with hours, service area and a Sample rating.
- Their route visible: a stylised map with five route lines (Hill→North Boulder, Table Mesa→Louisville, etc.) so they see their street on the page.

## 3. The contractor's first 5 seconds
The route-line signature: every section is drawn as a route from one place to another, with start/end pins and a distance label. No other mover in Boulder shows the town's moves as a connected trip down the page. It reads as local knowledge, not a template.

## 4. Objections and where each is answered
| Fear | Section |
|---|---|
| Hour creep / no number | hero proof line + estimator tool + sample price block |
| Stuff held hostage | process section: wrap → load → place, guarantee token |
| Damage to hallway/furniture | process photo + guarantee line |
| Junk dumped illegally | haul-away section: donation → recycling → landfill order |
| Crew never shows / late | open-now badge + hours + reviews naming streets and times |
| Canyon road / narrow drive | mountain-move route story + small-truck note |
| August lease chaos | lease-calendar tool + early-book note |
| Downsizing guilt | keep/donate/haul sorter + estate-cleanout review |

## 5. Conversion paths
- Primary: `[[call]]` in header, hero, mobile bar; `#contact` form at page end.
- Secondary: estimator → prefill form; ZIP checker → prefill form; service card "Price it" → prefill form.
- Phone is always one thumb-reach away on mobile via the sticky bar.

## 6. What this direction is NOT
- Not A's inventory-tag system (no numbered tags, no kraft paper, no condensed grotesk).
- Not B's load-meter ledger (no dark dashboard, no mono numbers, no running truck fill).
- Not a generic "stress-free movers" page: no smiling couple, no truck lineup, no nationwide language. This is Boulder-specific, color-led, serif-voiced, route-drawn.

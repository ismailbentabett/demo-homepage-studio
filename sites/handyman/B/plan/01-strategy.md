# Strategy — handyman-B (Pegboard Home Repair)

1. **The one job.** A busy Ann Arbor homeowner lands, builds a punch list in the estimator tool, sees the typical hour band and sample price, and clicks "Price it" to send the list + photos within 25 seconds.
2. **Homeowner's first 5 seconds.** H1 kicker "Handyman Services · Ann Arbor, MI"; headline "Pick your jobs. See the hours."; primary button "Build my list"; proof line "4.8 stars · 212 reviews (Sample rating)"; hero mosaic of small-job photos (TV mount, drywall patch, faucet) arranged like tools on a pegboard.
3. **Contractor's first 5 seconds.** The page is a workshop pegboard: every service is a tool outline with a hang-tag showing typical hours, and adding an item lifts the tool off the wall into a running list tray. No other local handyman shows prices before the call.
4. **Objections → sections.**
   - "Nobody calls back for small jobs" → Hero + Punch-list tool (instant hour band).
   - "They'll show up at 4" → Hours/Open-now strip + visit-length estimate in tool output.
   - "Trip charge for one thing" → Price-by-visit table (Sample pricing) + half-day fit indicator.
   - "Sloppy patch" → Detail photo grid (clean patch, level shelf, straight caulk bead).
   - "They'll try something they shouldn't" → Fix-or-specialist triage tool + honest-limits statement.
   - "No prices" → Sample price tags under each tool outline + estimator output.
5. **Conversion paths.** Primary: "Build my list" → estimator → "Price it" prefill form. Secondary: sticky mobile bar with [[call]] + "Text photos" link to #contact. Phone always visible in header and mobile bar; ZIP checker sits above the form to confirm coverage before the visitor types.
6. **What this direction is NOT.** Unlike A (time-card process narrative), B does not tell a morning story or use timestamp rails. Unlike C (neighborhood walk), B does not organize by street or house type. B avoids any cartoon/clip-art handyman, starburst "No job too small!", and generic service-icon grids that list roofing/HVAC/electrical panels.
